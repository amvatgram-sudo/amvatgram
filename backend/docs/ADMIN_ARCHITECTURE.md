# معماری پنل سوپرادمین و پایش زنده امواتگرام (Super Admin & Master Command Center)
## Architecture of Independent Master Admin Dashboard

این سند نحوه تفکیک، طراحی امنیتی و اتصال پنل سوپرادمین مستقل به هسته امواتگرام را تشریح می‌کند.

---

### ۱. معماری کلی: استقلال در استقرار + اشتراک پایگاه داده و وب‌سوکت
پنل مدیریت ارشد نباید یک تب ساده داخل اپ عمومی باشد؛ بلکه یک کنسول فرماندهی امن با لایه‌های دفاعی مستقل است.

```text
┌─────────────────────────────────┐       ┌───────────────────────────────────┐
│     اپلیکیشن عمومی امواتگرام     │       │     کنسول سوپرادمین امواتگرام     │
│   (کاربران، صاحبان عزا، مهمان)    │       │     (صاحب پروژه / فرماندهی کل)    │
│  - ثبت آگهی، تسلیت، مسیریابی    │       │  - مانیتورینگ زنده، تأیید و ابطال │
│  - دامنه/مسیر: amvatgram.ir     │       │  - مسیر: amvatgram.ir/master-ops  │
│                                 │       │    (یا کنسول ساب‌دامین اختصاصی)   │
└────────────────┬────────────────┘       └─────────────────┬─────────────────┘
                 │                                          │
                 │   REST API / Real-time WebSocket         │
                 ▼                                          ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                 هسته مرکزی بک‌اند و پایگاه داده مشترک                      │
│ - کنترل دسترسی بر اساس نقش (RBAC: SUPER_ADMIN, MODERATOR, OWNER, USER)     │
│ - رویدادهای زنده (Live Event Bus: ثبت آگهی جدید، گزارش خطا، ترافیک مساجد)  │
│ - ثبت ردپا و لاگ‌های امنیتی (Audit Logs)                                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

### ۲. قابلیت‌های اختصاصی پنل صاحب اپلیکیشن (Super Admin Features)

1. **رادار و مانیتورینگ زنده (Live Activity Feed):**
   - مشاهده درلحظه تمام رویدادها: «فلان شماره آگهی ثبت کرد»، «فلان کاربر پیام تسلیت فرستاد»، «۵۰ نفر آگهی حاج محمد را دیدند».
2. **صف تأیید و بررسی آگهی‌ها (Approval & Moderation Queue):**
   - دیدن آگهی‌های خام ثبت شده توسط مردم مریوان پیش از انتشار عمومی.
   - ابزار بازبینی عکس متوفی، متن اعلامیه و ساعت‌های مراسم با یک کلیک (تأیید فوری / رد با ارسال پیامک دلیل به صاحب عزا).
3. **مرکز مداخله اضطراری (Emergency Kill-Switch & Edit):**
   - تعلیق فوری هر آگهی، بستن کامنت‌های یک آگهی خاص در صورت بروز تنش خانوادگی یا شایعه.
4. **مدیریت بانک مساجد و آرامستان‌های مریوان (Places Master):**
   - افزودن، ویرایش نام امام جماعت، شماره خادم و مختصات GPS مساجد جدید شهرستان.
5. **آمار تحلیلی و ترافیک (Analytics & Insights):**
   - بیشترین مساجد پرتردد مریوان، ساعات اوج بازدید، نرخ تعامل مردم و دانلود پوسترهای ترحیم.
6. **لاگ بازرسی امنیتی (Security Audit Logs):**
   - ثبت دقیق لاگین‌ها، آی‌پی‌های مشکوک و تلاش‌های ناموفق.

---

### ۳. سطوح امنیتی و دسترسی
- ورود فقط با شماره موبایل ثبت شده سازنده (Super Admin) + تأیید دو مرحله‌ای (2FA / OTP سخت‌گیرانه).
- توکن امنیتی مجزا با نقش `SUPER_ADMIN`.
- بررسی سطح دسترسی در تمام Routeها و APIها.
