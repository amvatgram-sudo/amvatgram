# Frontend

رابط کاربری React/Vite پروژه در این پوشه قرار دارد.

- `src/`: components, contexts, services, types, data و assets
- `public/`: فایل‌های public
- `index.html`: entry HTML
- `vite.config.ts`: تنظیمات Vite
- `Dockerfile.web`: image تولید frontend
- `deploy/`: تنظیمات Nginx

اجرای frontend از ریشه پروژه:

```bash
npm run dev
```
