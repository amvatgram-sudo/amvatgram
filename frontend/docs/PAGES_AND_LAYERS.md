# معماری صفحات، لایه‌ها و جریان کاربری سامانه امواتگرام
## Architecture of Pages, Layouts & System Layers

این سند تفکیک دقیق تمام صفحات رابط کاربری، لایه‌های ساختاری نرم‌افزار و جریان حرکت کاربر (User Flow) در سامانه امواتگرام را به عنوان مرجع تعیین می‌کند.

---

### بخش اول: لیست کامل صفحات اجرایی نرم‌افزار (Views & Screens)

سامانه امواتگرام برای نسخه MVP شامل **۸ صفحه اصلی** به همراه **۴ مدال/کامپوننت کلیدی تمام‌صفحه** است:

1. **صفحه اصلی و فید آگهی‌ها (Home / Grief Feed Page)**
   - نوار وضعیت و ابزار جستجوی سریع متوفی (بر اساس نام، نام خانوادگی، نام پدر، مسجد یا محله)
   - فیلتر هوشمند مذهب (اهل سنت / اهل تشیع / همه) و وضعیت مراسم (امروز، فردا، برگزار شده)
   - کارت‌های محترمانه متوفیان با عکس، نام، تاریخ و نشان مذهبی
   - دسترسی فوری به ثبت آگهی، تماس با صاحب عزا، قلب سیاه و مسیریابی

2. **صفحه جزئیات آگهی ترحیم (Grief Ad Detail Page)**
   - عکس کامل و مشخصات شناسنامه‌ای و خانوادگی متوفی
   - اطلاعات دقیق مراسم: ساعت خاکسپاری، مسجد فاتحه‌خوانی آقایان، مسجد یا مکان بانوان
   - ویجت مسیریابی مستقیم (اتصال تک‌کلیک به نشان، گوگل‌مپ، ویز و اپل‌مپ)
   - شماره‌های تماس بستگان جهت عرض تسلیت تلفنی
   - بخش ابراز همدردی: شمارنده قلب سیاه و ثبت پیام‌های تسلیت با قالب‌های آماده
   - دکمه اشتراک‌گذاری سریع و دانلود پوستر اعلامیه

3. **صفحه ثبت آگهی ترحیم (Create Grief Ad Page - فرم مرحله‌ای چندگانه)**
   - مرحله ۱: اطلاعات متوفی (نام، نام خانوادگی، نام پدر، تاریخ فوت، مذهب، آپلود عکس با برش شایسته)
   - مرحله ۲: زمان‌بندی و مکان‌ها (انتخاب آرامستان، مسجد زنانه و مردانه از لیست مساجد مریوان یا ثبت مکان جدید با لوکیشن)
   - مرحله ۳: مشخصات صاحب عزا و بستگان (نسبت، شماره تماس هماهنگی و احراز هویت)
   - مرحله ۴: پیش‌نمایش اعلامیه و ارسال برای تأیید مدیر (`Pending Moderation`)

4. **صفحه سازنده و دانلود اعلامیه تصویری (Memorial Poster Studio)**
   - انتخاب قالب متناسب با مذهب و زبان (کُردی، فارسی، عربی)
   - درج خودکار شعر، آیات قرآن و مشخصات مراسم روی تصویر
   - خروجی استاندارد با رزولوشن بالا برای استوری اینستاگرام، وضعیت واتساپ و چاپ

5. **صفحه ورود و مدیریت حساب کاربری (Auth & Account Profile)**
   - ورود/ثبت‌نام با شماره موبایل و کد یکبار مصرف (OTP)
   - انتخاب مذهب پیش‌فرض حساب کاربری (جهت شخصی‌سازی متون و ادعیه)
   - مشاهده لیست آگهی‌های ثبت شده توسط کاربر و وضعیت آن‌ها (در انتظار تأیید، تایید شده، رد شده)
   - درخواست ویرایش اطلاعات مراسم برای صاحب عزا

6. **پنل مدیریت و بازبینی آگهی‌ها (Admin Moderation Dashboard)**
   - صف بررسی آگهی‌های جدید (تایید صحت اطلاعات، تأیید تصویر و متن قبل از انتشار عمومی)
   - امکان رد آگهی با درج علت برای صاحب عزا، یا تایید و انتشار فوری
   - مدیریت گزارش‌های خطا و درخواست‌های ویرایش ساعت مراسم

7. **صفحه مدیریت بانک اماکن و مساجد (Locations & Mosques Directory)**
   - فهرست مساجد، حسینیه‌ها و آرامستان‌های فعال مریوان به همراه مختصات GPS و آدرس دقیق
   - قابلیت انتخاب آسان توسط خانواده‌ها در زمان ثبت مراسم

8. **صفحه آرشیو و جستجوی پیشرفته (Archive & Memorials History)**
   - آگهی‌هایی که بیش از ۷ روز از تاریخ مراسم آن‌ها گذشته و به آرشیو منتقل شده‌اند
   - امکان جستجوی یادبودها بر اساس سال، ماه و محله

### بخش دوم: لایه‌های معماری نرم‌افزار (The Architectural Layers)

سیستم از منظر مهندسی نرم‌افزار در **۴ لایه افقی (Horizontal Layers)** طراحی شده است:

```text
┌─────────────────────────────────────────────────────────────┐
│  Layer 1: Presentation & UI Layer (React, Tailwind, Motion) │
│  - Views (Home, Detail, Create, Profile, Admin)             │
│  - Reusable Components (AdCard, CompassMap, CondolenceBox)  │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│  Layer 2: State & Business Logic Layer (Hooks, Stores)       │
│  - AdStore (CRUD, Filter by Madhhab, Search Query)          │
│  - AuthStore (Session, User Role: Guest/User/Owner/Admin)    │
│  - Moderation Engine & Religion Context Rules               │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│  Layer 3: Service & Integration Layer (APIs, Deep-linking)   │
│  - Navigation DeepLinker (Neshan, Waze, GoogleMaps)         │
│  - Image Generator Engine (Canvas/Poster Renderer)          │
│  - SMS / OTP Provider Interface                             │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│  Layer 4: Data & Persistence Layer                          │
│  - Relational Models (Users, GriefAds, Ceremonies, Places)  │
│  - Local Storage / Remote Database Client                   │
└─────────────────────────────────────────────────────────────┘
```
